# airbnb-clone-project
Airbnb Clone is a full-stack web app that replicates key Airbnb features like user login, property listings, and bookings. Built with React, Flask or Node.js, and PostgreSQL/MySQL, it’s designed to explore scalable, responsive, and tech-driven housing solutions.

# UI/UX Design Planning
### Goals  
- Make the app easy to use and visually appealing  
- Help users find and book properties quickly  
- Ensure smooth experience on phones and computers  

### Key Features  
- Property search and filters  
- Booking calendar  
- Simple checkout process  

### Main Pages  

| Page Name               | Description                                                                 |
|------------------------|-----------------------------------------------------------------------------|
| **Listing View**        | Shows all available properties with images and basic info.                 |
| **Details View**        | Displays full property info, reviews, and booking options.                 |
| **Checkout View**       | Lets users confirm dates, enter payment, and finish booking.               |

### Why It Matters  
A user-friendly design makes booking faster, easier, and more enjoyable. It builds trust and helps users avoid mistakes—especially when paying online

## 🎨 UI/UX Design Planning

**Color Styles**  
- Primary Red: `#FF5A5F`  
- Teal Accent: `#00A699`  
- Dark Gray: `#484848`  
- Light Gray: `#F7F7F7`  
- Orange CTA: `#FC642D`  
- White: `#FFFFFF`

**Typography**  
- Font: `'Montserrat', sans-serif`  
- Weights: 400, 600, 700  
- Sizes: 14px (body), 18px (subheading), 24px (heading), 32px (hero)

**Why It Matters**  
Defining design properties ensures consistency, speeds up development, improves accessibility, and aligns the clone with Airbnb’s visual identity.

# UI Component Patterns

- **Navbar** – Logo, search bar, navigation links, responsive layout  
- **Property Card** – Image, title, location, price, rating, hover effects  
- **Footer** – Informational links, social icons, responsive design  
- **Date Picker** – Calendar for check-in/check-out selection  
- **Location Filter** – Dropdown or autocomplete for city/region  
- **User Profile Menu** – Avatar, bookings, favorites, settings, logout
